## 권장 열람 순서

처음에는 `먼저 읽기`로 전체 구성을 파악한 뒤, `전체 작업 내역`과 `트러블슈팅`을 확인하는 순서를 권장합니다. 이력서 작성이나 면접 준비 시에는 `이력서·면접 정리`를 활용하고, 세부 내용을 검증할 때는 `근거 목록`을 참고할 수 있습니다.

다른 PC나 새로운 Codex 대화에서 포트폴리오와 이력서 작업을 이어갈 때는 `포트폴리오·이력서 Codex 인수인계`를 먼저 확인합니다. `portfolio-source/`에는 GitHub Pages용 포트폴리오 소스가, `output/`에는 이력서와 자기소개서 작업본이 있습니다.

> 문서에는 프로젝트 구조와 구현 경험을 정리했으며, 실제 비밀키·비밀번호·운영 인증정보는 포함하지 않았습니다.
